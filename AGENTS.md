# AGENTS.md — Instructions for AI Coding Agents

This file guides AI agents (and humans) working in this repository. Follow it to keep changes consistent, safe, and CI-green.

## 1. Project Overview

URL Shortener — full-stack monorepo with:

- `backend/` — Fastify + TypeScript API that creates and resolves short URLs. Short codes are generated by a Postgres `BEFORE INSERT` trigger (`generate_short_url()`), with application-level retry on `P2002` collisions (`backend/src/features/shorten-url/url.service.ts:34` and `:73`).
- `frontend/` — React 19 + Vite + TypeScript + Tailwind CSS SPA. Two routes: `/` (create) and `/r/:shortCode` (resolve & redirect). Includes `fetchWithTimeout` utility with caller-signal precedence (`frontend/src/lib/fetchWithTimeout.ts:27`).
- `infrastructure/` — Nginx reverse proxy (`infrastructure/nginx/nginx.conf:8`) load-balancing 3 backend replicas + Postgres host setup guide (`infrastructure/database/setup.md:1`).
- CI — GitHub Actions (`.github/workflows/ci.yml:1`) runs backend tests+build, frontend lint+test+build, Playwright E2E, and Docker build.

Node `24.8.0`, `pnpm@10.18.3`, `pnpm-workspace.yaml` per package.

## 4. Common Commands

All commands assume `pnpm` 10.x. Run from the indicated directory.

### Backend (`backend/`)

```bash
pnpm install --frozen-lockfile
pnpm prisma generate          # regenerate client after schema/migration changes
pnpm dev                      # tsx watch src/server.ts (http://localhost:3000)
pnpm build                    # tsc -> dist/
pnpm start                    # node dist/server.js (production)
pnpm test                     # vitest run (node env, src/**/*.test.ts)
pnpm test:watch               # vitest watch
pnpm test:coverage            # vitest run --coverage (v8)
```

```bash
pnpm install --frozen-lockfile
pnpm dev                      # vite (http://localhost:5173)
pnpm build                    # tsc -b && vite build -> dist/
pnpm preview                  # vite preview
pnpm lint                     # eslint .
pnpm test                     # vitest run (jsdom, src/test/setup.ts)
pnpm test:watch
pnpm test:coverage
pnpm test:e2e                 # playwright test (chromium)

pnpm exec playwright install --with-deps chromium  # first-time setup
```

```bash

docker build -t backend:1.0 ./backend

docker compose -f backend/docker-compose.yaml up --build

# Nginx expects backends on 3001/3002/3003 -> upstream nodejs_cluster
# See infrastructure/nginx/nginx.conf:8
```

## 5. Architecture Notes

- **Short-code generation:** Delegated to Postgres. `BEFORE INSERT` trigger `set_short_url` calls `generate_short_url()` which sets `NEW."short_code" = substring(md5(random()::text || clock_timestamp()::text) from 1 for 7)` when `short_code IS NULL`. Only `originalUrl` is sent from the app (`backend/src/features/shorten-url/url.service.ts:66`). Prisma returns the trigger-filled row.
- **Collision handling:** Unique index on `short_code`. Concurrent inserts may both pass the trigger's `NOT EXISTS` check; loser gets `P2002`. Service retries up to `MAX_CREATE_ATTEMPTS = 5` (`backend/src/features/shorten-url/url.service.ts:7`). Detect via `PrismaClientKnownRequestError` or duck-typed `{code: "P2002"}` (`backend/src/features/shorten-url/url.service.ts:34`).
- **Rate limiting:** `@fastify/rate-limit` with `IORedis`/`Valkey` when `REDIS_URL` is set; in-memory fallback. Both `GET /api/shorten-url/:shortCode` and `POST /api/shorten-url` are `max: 10 / 1 minute` (`backend/src/features/shorten-url/url.routes.ts:14`, `:23`). `buildApp({ redisClient: null })` forces in-memory; `enableRateLimit: false` disables it (used in tests).
- **Validation:** Fastify JSON Schema (`backend/src/features/shorten-url/url.schema.ts:3`) — `originalUrl` string 1–2048 chars, `shortCode` `^[A-Za-z0-9_-]+$` 1–10 chars. Service-level `assertHttpUrl` enforces `http:`/`https:` (`backend/src/features/shorten-url/url.service.ts:17`).
- **CORS:** Single origin from `env.BASE_URL` (`backend/src/app.ts:28`). No credentials.
- **Frontend routing:** `react-router` 8.x (`frontend/src/App.tsx:8`) — `BrowserRouter` with `index` and `/r/:shortCode`. `RedirectPage` fetches `GET /api/shorten-url/:shortCode` via `fetchWithTimeout` and `window.location.assign` on success, else `navigate("/")` (`frontend/src/pages/RedirectPage.tsx:30`).
- **Timeout utility:** `fetchWithTimeout(input, init, 10_000)` — merges external `AbortSignal`, timeout abort maps to `FetchTimeoutError`, external abort propagates untouched (`frontend/src/lib/fetchWithTimeout.ts:27`).

## 6. Conventions & Guardrails

### TypeScript
- Backend: `NodeNext` modules, `verbatimModuleSyntax`, `strict`, `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess` (`backend/tsconfig.json:2`). Use `import ... from "./foo.js"` (`.js` extension required).
- Frontend: `tsconfig.app.json` / `tsconfig.node.json`, `react` + `tailwindcss` Vite plugins (`frontend/vite.config.ts:6`).

### Code Style
- Run `pnpm lint` (frontend) before PRs — CI enforces it (`.github/workflows/ci.yml:64`).
- Prefer editing existing files over creating new ones. Keep diffs minimal.
- Do not manually edit `backend/src/generated/prisma/**` — regenerate via `pnpm prisma generate`.
- Do not add secrets to git. `.env` is ignored (`.gitignore:70`); commit only `.env.example`.
- Husky/leave hooks: respect existing git hooks. Do not `--no-verify` unless explicitly instructed.

### Testing
- Backend: `vitest` `environment: node`, `src/**/*.test.ts` (`backend/vitest.config.ts:4`). Mock Prisma/Redis; no real DB needed for unit tests. Tests may inject `redisClient` via `buildApp` options.
- Frontend unit: `vitest` `environment: jsdom`, `src/test/setup.ts`, exclude `e2e/**` (`frontend/vitest.config.ts:7`). Uses `@testing-library/react`, `msw`.
- Frontend E2E: `playwright` `testDir: ./e2e`, chromium only, `webServer` auto-starts `pnpm dev` (`frontend/playwright.config.ts:20`). Artifacts in `frontend/playwright-report/` and `frontend/test-results/` (gitignored).
- Always verify: before claiming done, run `pnpm test` in touched packages and `pnpm build` if you changed buildable code.

### Database
- Prisma schema at `backend/prisma/schema.prisma:10` (`model Url` → table `urls`, `shortCode` nullable `VarChar(10)` for trigger).
- Migrations live in `backend/prisma/migrations/` — do not squash or rename. Apply with `pnpm prisma migrate dev` (local) / `pnpm prisma migrate deploy` (prod). Keep `migration_lock.toml` in sync.
- For Dockerized backends talking to host Postgres, follow `infrastructure/database/setup.md:5` (docker gateway, `postgresql.conf` `listen_addresses`, `pg_hba.conf` subnet, restart).

### Git & CI
- CI triggers on `push` to `master` and all PRs, with `concurrency: ci-${{ github.ref }}` cancel-in-progress (`.github/workflows/ci.yml:9`). Four jobs: `backend`, `frontend`, `frontend-e2e`, `backend-image`.
- Keep `pnpm-lock.yaml` in sync — CI uses `--frozen-lockfile` (`.github/workflows/ci.yml:39`, `:63`).
- Conventional commits preferred (`feat:`, `fix:`, `test:`, `ci:`, etc. — see `git log --oneline` history).
- Do not force-push or update `git config` unless asked. Inspect `git status`, `git diff`, `git log --oneline -10` before committing.

### What NOT to Do
- Do not create `.md` docs unless requested (this file is an explicit exception).
- Do not add dependencies without checking `package.json` scripts and `vitest`/`vite` configs still work.
- Do not bypass rate-limit or trigger logic with ad-hoc code generation — keep generation in DB.
- Do not hardcode URLs/ports; use `env.*` / `import.meta.env.VITE_*`.

## 7. Quick Fix Checklist

- Build fails after `schema.prisma` change → `pnpm prisma generate`.
- CORS error in dev → check `BASE_URL` matches frontend origin, `VITE_API_URL` points at backend.
- Rate-limit issues in tests → `buildApp({ redisClient: null })` or `{ enableRateLimit: false }`.
- Playwright `webServer` timeout → ensure `5173` is free, `pnpm dev` works standalone.
- Docker backend can't reach Postgres → verify `infrastructure/database/setup.md` host config and `DATABASE_URL` uses `host.docker.internal` or gateway IP.
